Methods and credibility

What the code actually does today.

Implemented

  • Equilibrium for reactions and internal forces
  • Double integration of EI d2y/dx2 = M(x) with continuity conditions
  • Compatibility equations for indeterminate beams and fixed–fixed bars
  • Conjugate beam, moment-area, superposition, unit load
  • Method of joints and sections for trusses
  • Euler, Johnson, secant buckling; Mohr's circle

Verification

  • Python beam solver: automated tests against closed-form results (reactions, Mmax, deflections)
  • Method cross-checks: every deflection method must agree
  • Browser calculators were spot-checked by hand
