Sign conventions

  • Beam: loads down +, reactions up +, applied couples clockwise +, sagging moment +; deflection y up +, slope counter-clockwise +.
  • Truss and bars: tension +. Mohr's circle: τxy positive on the +x face pointing +y; θ counter-clockwise from x.
  • Units are not enforced. Use a consistent set (for example kN, m, kN·m² or N, mm, MPa).

Run locally

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
pytest
uvicorn api.index:app --reload   # open http://127.0.0.1:8000

Open the site through that address. Opening the HTML files directly shows the pages, but the beam solver needs the server.

API

POST /api/solve
{"length":10,"supports":[{"type":"pin","x":0},{"type":"roller","x":10}],
